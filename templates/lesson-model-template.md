---

# Lesson Retrospective

After real use, record:

- what learners understood quickly;
- where confusion appeared;
- which examples worked;
- which prompts encouraged dependency rather than understanding;
- what verification steps were skipped;
- what should change in the next lesson version.

## Recommended HLAPM progression

`Ask → Observe → Understand → Explain → Reproduce → Adapt → Diagnose → Verify → Prompt From Knowledge → Assess → Challenge → Independent Practice → Teach → Systematize`
