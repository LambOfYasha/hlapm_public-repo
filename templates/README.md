# Templates

This directory is for reusable supporting records that help learners and teams apply Human-Led AI Project Mastery consistently.

Templates should make important reasoning and evidence visible without turning the process into bureaucracy.

Useful template categories may include:

- project learning records;
- learning-debt registers;
- verification checklists;
- prompt review records;
- role capability matrices;
- manager review records;
- case-study records;
- workflow retrospectives.

Existing specialized templates currently live with their systems:

- [`assessment/assessment-record-template.md`](../assessment/assessment-record-template.md)
- [`challenge/challenge-record-template.md`](../challenge/challenge-record-template.md)
