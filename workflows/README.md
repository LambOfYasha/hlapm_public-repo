# Workflows

This directory is for reusable human-led AI processes that connect learning to meaningful project execution.

A workflow should make clear:

- the real objective;
- human responsibilities;
- AI responsibilities;
- assumptions and dependencies;
- verification points;
- failure/recovery behavior;
- what capability the learner should gain;
- what evidence demonstrates that capability;
- how the output returns to the real project.

Prefer durable principles over instructions tied to one temporary product interface. Tool-specific implementations are welcome when clearly labeled as current implementations rather than timeless rules.

Suggested progression:

`Discover → Learn → Plan → Perform → Verify → Assess → Challenge → Integrate → Reflect → Systematize`
