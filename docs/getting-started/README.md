# Getting Started

Human-Led AI Project Mastery begins with one question:

> **After AI helps me accomplish something, how much more capable am I of understanding or performing that type of work myself?**

## Bring a Real Project

Whenever practical, start with something you already genuinely want to accomplish. Authentic work creates better evidence than disposable exercises because the result must survive real constraints, real verification, and real consequences.

## Three Useful AI Modes

### 1. Hand-Off Mode
Use AI primarily for the result. This can be appropriate when the skill itself is low-value to you and the risk is controlled.

### 2. Pair Mode
Use AI to help perform the work while keeping you involved in decisions, explanation, verification, and correction.

### 3. Mastery Mode
Use AI deliberately to reduce unnecessary dependency over time. Ask for teaching, expose assumptions, reproduce important steps, adapt the workflow, diagnose failures, and eventually build prompts from acquired knowledge.

No mode is morally superior in every task. The important question is whether your level of dependency is intentional and appropriate to the stakes.

## Progression

`Observe → Explain → Reproduce → Adapt → Diagnose → Verify → Prompt → Assess → Challenge → Teach → Systematize`

You may move backward when a new project exposes learning debt. That is expected.

## Keep Three Scores Separate

**Project:** Did the work get completed?

**Knowledge:** What can you personally understand, explain, reproduce, adapt, diagnose, verify, prompt for, or teach?

**Workflow:** Can you estimate, prioritize, organize, recover, verify, and finish reliably?

## First Practical Cycle

1. Choose one meaningful project need.
2. Ask AI to help while explaining important concepts and assumptions.
3. Identify what you still could not reproduce or verify independently.
4. Record those gaps as learning debt.
5. Perform a bounded live-project assessment.
6. If evidence supports progression, perform a challenge that extends the same project.
7. Integrate the finished result.
8. Update what you can now demonstrate and what remains untested.
