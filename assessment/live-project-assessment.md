# Live-Project Assessment Workflow

## 1. Identify the Capability
State exactly what the learner is expected to demonstrate and which prior teaching or practice it extends.

## 2. Select Authentic Project Work
Choose a bounded task that advances a real project and produces a meaningful deliverable.

## 3. Define Ownership
State what the learner must do personally and what assistance AI may provide.

## 4. Define Evidence
Specify observable evidence such as a learner-authored explanation, implementation, correction, prompt, test result, decision record, verification log, or demonstration.

## 5. Attempt Before Solution
When the capability itself is being evaluated, do not give the complete answer before a genuine learner attempt unless safety, accessibility, or a hard blocker requires intervention.

## 6. Verify
Use an appropriate verification method. AI review can assist, but consequential claims should not rely on uncritical AI self-evaluation.

## 7. Grade Demonstrated Capability
Use the mastery scale only for what the evidence supports. Keep untested dimensions untested.

## 8. Record Learning Debt
Document what the project required that the learner still cannot independently explain, reproduce, adapt, diagnose, verify, or direct.

## 9. Integrate the Result
The assessment output should be used, documented, corrected, or merged into the live project where appropriate.

## 10. Decide the Next Step
Possible next steps include additional teaching, guided practice, another assessment, independent practice, or progression to `[challenge]` when evidence supports increased production pressure.
