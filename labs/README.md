# Labs

**Status:** EXPERIMENTAL AREA

Labs contain exploratory methods, experiments, prototype assessments, tool-specific trials, and ideas that are not yet established public standards.

Use labs to preserve useful experimentation without silently promoting it to approved guidance.

A lab should ideally record:

- hypothesis or question;
- project context;
- method;
- expected result;
- actual result;
- failures or surprises;
- verification;
- learner impact;
- recommendation: discard, revise, repeat, or promote.

Material should move out of Labs only after meaningful review and evidence justify broader use.
