# Live-Project Challenge Workflow

## 1. Read Assessment Evidence
Start from what the learner actually demonstrated, including learning debt and untested areas.

## 2. Select an Authentic Project Extension
Choose the next meaningful project need rather than inventing difficulty for its own sake.

## 3. Calibrate Increased Challenge
Increase ambiguity, independence, scope, verification responsibility, or delivery pressure according to demonstrated readiness.

## 4. Assign Part A — Learner-Authored Prompt
Provide the objective and rubric, but do not write the final advanced prompt for the learner before their attempt when prompt construction is being evaluated.

## 5. Define Part B — Finished Product
Specify the real deliverable, acceptance criteria, verification method, integration step, and definition of done.

## 6. Lock the Deadline Before Execution
Record the start, exact deadline in the learner's local timezone, milestones when useful, and legitimate deadline-adjustment conditions.

## 7. Execute With Evidence Capture
Track major decisions, failures, corrections, AI assistance, and learner-owned work honestly.

## 8. Verify the Product
Use appropriate tests, sources, review, inspection, or other evidence. Do not allow the AI that produced the work to be the only unquestioned evaluator when consequences matter.

## 9. Grade Three Dimensions Separately

- Knowledge / Prompt Mastery
- Product / Application Mastery
- Workflow / Deadline Discipline

## 10. Update Mastery and Debt
Record newly demonstrated capability, untested capability, learning debt, and workflow-discipline debt.

## 11. Integrate the Result
Use the artifact in the live project where appropriate and document what changed.

## 12. Select the Next Progression
Possible next steps include remediation, reassessment, another challenge, independent production, teaching, or systemization.

`learn → practice → assess → challenge → independent practice → teach/systematize`
