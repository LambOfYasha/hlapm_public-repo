# Live-Project Challenge

Assessment asks:

> **What can you demonstrate?**

Challenge asks:

> **Can you convert that demonstrated knowledge into dependable, finished work under realistic constraints?**

`[challenge]` is a post-assessment mastery-and-delivery framework. It should increase application pressure without confusing speed with knowledge or creating arbitrary stress.

## Two Required Deliverables

### Part A — Advanced Prompt Authoring

The learner authors a sophisticated prompt from acquired domain knowledge. When relevant, it should intentionally address:

- project objective;
- current state and context;
- constraints and non-goals;
- assumptions and dependencies;
- human-owned decisions;
- AI responsibilities;
- expected deliverable;
- quality criteria;
- verification;
- failure/recovery considerations;
- integration or continuation instructions.

AI should not write the final prompt before the learner's attempt when prompt design is being evaluated.

### Part B — Finished Project Product

The learner uses acquired knowledge, their prompt, permitted AI assistance, and project tools to produce a finished live-project deliverable with explicit acceptance criteria, verification, integration, definition of done, and deadline.

## Readiness

Recommended defaults:

- **Mastery 0–2:** normally return to teaching or assessment.
- **Mastery 3–4:** Applied Challenge — bounded scope, explicit milestones, moderate scaffolding.
- **Mastery 5–6:** Production Challenge — less scaffolding, stronger diagnosis and verification.
- **Mastery 7–8:** Mastery Challenge — independent planning, prompting, execution, verification, and explanation.
- **Mastery 9:** System-Level Challenge — standards, delegation, training, infrastructure, or organizational workflow improvement.

Actual evidence overrides the numeric default.

## Modes

- `[challenge:guided]` — milestones and limited structural hints.
- `[challenge:standard]` — normal production challenge with restrained AI help.
- `[challenge:mastery]` — minimal scaffolding and stronger independent verification.
- `[challenge:team]` — adapts evidence and review for a real team/employee role.

## Evaluation

Always keep these visible separately:

1. **Knowledge / Prompt Mastery**
2. **Product / Application Mastery**
3. **Workflow / Deadline Discipline**

A missed deadline does not erase genuine knowledge. An on-time AI-produced artifact does not prove mastery.
