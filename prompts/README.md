# Prompt Patterns

Prompts in this repository are **learning and workflow structures**, not magic formulas.

A useful prompt should become more understandable and adaptable as the learner gains domain knowledge. Do not judge prompt quality by length alone.

Current reusable patterns:

- [`assessment.md`](assessment.md) — live-project capability demonstration
- [`challenge.md`](challenge.md) — post-assessment mastery and delivery under explicit constraints

When adapting these patterns, preserve clear human responsibilities, AI responsibilities, verification, and evidence boundaries.
